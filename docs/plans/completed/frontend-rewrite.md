# 计划：React 前端重写

- 状态：已完成 | 开始：2026-11-20 | 完成：2026-11-22 | 分支：`dev`（2026-11-21 起；此前在 `ui` 分支的独立 worktree），合并进 `main`：`aebde87` | 关联设计：[frontend.md](../../design/frontend.md)（已采纳）、[ADR-0008](../../architecture/adr/0008-react-frontend.md)

## 目标

用 React + pnpm 重写前端，覆盖新后端已有的全部用户功能。视觉以火星红为唯一强调色，暖色中性色为底，提供亮色和深色两套主题。按 [data-flow.md](../../architecture/data-flow.md) 的客户端约定实现连接与同步，把后端的可靠性（发送确认、幂等重发、断线补拉、多端同步、已读回执）做成用户看得见的交互。

## 结果

2026-11-22 完成。前端覆盖了后端已有的全部用户功能：认证、实时消息、联系人与群组、设置与管理、文件与头像、一对一音视频通话。容器模式下由 nginx 容器经网关同源提供，可以开放给局域网访问，coturn 中继可选部署。功能状态见 [features.md](../../product/features.md)，部署见 [deployment.md](../../deployment.md#前端)，实施中的调整见设计第 10 节（共 89 条）。

- 前端代码放在本仓库 `web/`（2026-11-20 确认，ADR-0008）。包管理用 pnpm（[ADR-0004](../../architecture/adr/0004-frontend-pnpm.md)）。
- 不新增或修改后端接口。发现需要后端配合时，先记录到 [tech-debt.md](../tech-debt.md)，或在 `docs/plans/active/` 新建后端计划（[后端重构计划](../completed/backend-refactor.md)已完成），再与开发者确认。
- 和后端计划的依赖关系：
  - 第 7 阶段（文件）依赖后端步骤 6（media），第 8 阶段（通话）依赖后端步骤 7（通话信令）。两步都已于 2026-11-21 在 `dev` 上完成；`ui` 合并进 `dev` 后（`9a737ab`），`web/src/gen` 已包含 `media` 和通话信令的类型。
  - coturn 与 TURN 临时凭据下发推迟到前端阶段（后端计划步骤 7）。第 8 阶段开发者确认（2026-11-22）再推迟到第 9 阶段，与部署方式一起实施，提议见 [turn-relay.md](../../design/turn-relay.md)。
- 依赖：设计确认后，设计第 3.1 节列出的依赖视为已同意，安装时锁定当时的稳定版本；计划外的新依赖仍先询问。
- Compose、网关配置、CI 的改动属于对应阶段的任务；推送到远端仍需开发者同意。
- 每个阶段完成时，按 AGENTS.md 的文档同步表更新文档，并运行该阶段列出的验证。
