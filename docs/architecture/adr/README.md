## 新增 ADR

文件名 `NNNN-简短英文标题.md`，编号递增。模板：

```markdown
# ADR-NNNN 标题

- 状态：提议中 / 已采纳 / 已被 ADR-xxxx 替代 / 已废弃
- 日期：YYYY-MM-DD

## 背景
## 候选方案
## 决策
## 原因
## 代价与风险
## 适用条件（何时需要重新评估）
```

重大架构改造或技术选型变更，应先以“提议中”状态提交 ADR，经开发者确认后再实施。
