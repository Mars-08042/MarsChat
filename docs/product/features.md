# 功能清单

> 本清单是功能实现状态的**唯一权威记录**。功能变化时同步更新本表和对应模块文档。

状态均指后端接口（HTTP、gRPC 与 WebSocket），前端在重写中，尚未接入后端，见[前端计划](../plans/active/frontend-rewrite.md)。

**状态**：

- **已实现**：代码路径完整，有测试覆盖
- **部分实现**：可用但有明显限制或已知缺陷
- **未实现**：已确定要做或已知缺少，尚无代码

**验证情况**：写明自动化测试的位置或手动验证的日期。“单元”指对应服务 `internal/biz`、`internal/data` 的单元测试，“e2e”指 `test/e2e/` 下对应服务的测试文件（`make e2e`），“`make cluster-test`”指容器模式经网关的集群测试与故障实验（`test/cluster/`）。
