# 功能清单

> 本清单是功能实现状态的**唯一权威记录**。功能变化时同步更新本表和对应模块文档。

> **重构说明（2026-11-18）**：旧基线代码已在 `dev` 分支移除。新后端目前 account、social 服务的接口可用（见下方“新后端”），前端尚未重写。“新后端”之后的各节保留旧基线的功能与状态（列名为“旧基线状态”），作为 [后端重构计划](../plans/active/backend-refactor.md) 的功能基线；其中引用的 TD 编号已随旧代码关闭。新功能实现后按服务补入“新后端”。

**状态**：

- **已实现**：前后端代码路径完整
- **部分实现**：可用但有明显限制或已知缺陷
- **仅预留**：只有枚举、字段或界面，没有实际逻辑
- **开发中** / **计划中**：有对应计划文档时使用

**验证情况**：2026-11-07 首次整理时，所有条目都只做了代码静态核对。项目没有可运行的自动化测试，也没有启动系统做端到端验证，因此下表统一记为“未验证”。完成验证后请改为“手动验证 YYYY-MM-DD”或“自动化测试：<测试位置>”。
