# 产品概述

## 定位

MarsChat 是一个 Web 即时通讯系统：用户用邮箱注册登录，添加好友、加入群聊，收发文本、图片和文件消息，并可与好友进行一对一音视频通话；管理员可以封禁违规用户、解散违规群聊。

项目用于求职展示，重点是 IM 后端的可靠性与扩展性：消息不丢不重、会话内有序、多端同步、多实例部署下的跨节点投递，以及用故障实验和压测验证这些性质。后端已完成（2026-11-21），前端在 `web/` 用 React + pnpm 重写，见[前端计划](../plans/active/frontend-rewrite.md)。

## 角色

| 角色 | 能做什么 | 权限如何保证 |
|---|---|---|
| 访客 | 发送邮箱验证码、注册、登录 | 网关与服务按 IP 限流；验证码有发送间隔、每日上限和验证次数上限 |
| 普通用户 | 资料与设备管理、好友与拉黑、建群与入群、会话与消息、文件、通话 | 访问令牌（JWT）校验，退出、踢设备后立即失效；单聊要求是好友且未拉黑 |
| 群主、群管理员 | 修改群资料、审批入群、邀请、移除成员、禁言；群主还能设置管理员、转让、解散 | social 按群内角色校验 |
| 系统管理员 | 封禁与解封用户、解散任意群 | 令牌中的角色；只能用 `make grant-admin` 设置，没有接口 |

## 核心业务场景

1. **注册登录**：邮箱验证码注册；密码或验证码登录；同一账号可以在多个设备上同时登录，可以查看并踢掉其他设备。
2. **建立关系**：按用户 ID 申请好友，对方同意或拒绝；可以拉黑；建群时直接拉好友入群，或按群设置直接加入、申请审批。
3. **聊天**：在会话中收发文本、图片和文件，在线时实时送达，离线或断线后重连时补齐缺失的消息；会话列表显示未读数，单聊显示对方的已读位置；同一账号的多个设备同步消息和已读位置。
4. **通话**：向在线好友发起一对一音视频通话，对方所有在线设备同时响铃，任一设备接听后其他设备停止响铃；任一方挂断或断线时结束。
5. **管控**：管理员封禁用户后，该用户的令牌立即失效、长连接立即断开，无法再登录。

完整功能清单与实现状态见 [features.md](features.md)。

## 系统边界

**包含**：六个后端服务（HTTP、gRPC、WebSocket）；APISIX 网关；MySQL、Redis、Kafka、Consul；本地目录或阿里云 OSS 文件存储；SMTP 发送验证码邮件；浏览器之间的 WebRTC 媒体流（服务端只转发信令，可选 coturn 中继）；React 前端（nginx 容器，经网关同源提供）；监控、告警与链路追踪组件。全部由 Docker Compose 在单机上编排，可以在局域网内访问。

**当前不包含**：

- 移动端与桌面端客户端；公网部署（做法见 [web-deployment.md](../design/web-deployment.md) 第 4.3 节，没有实施）
- 离线推送、消息撤回、消息搜索、语音消息、删除会话
- 群通话、通话记录
- 找回密码、修改密码、注销账号
- 端到端加密、内容审核、管理员操作审计
- 组件高可用与跨机房部署
