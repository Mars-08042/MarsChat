# 产品概述

## 定位

MarsChat 是一个前后端分离的 Web 即时通讯系统：用户用手机号注册登录，添加好友、加入群聊，进行单聊、群聊和文件传输，并可在单聊中发起一对一音视频通话；管理员可以在后台管控用户和群聊。

当前代码是后续改造的**基线版本**。产品的最终定位、目标用户和改造方向尚未确定，由开发者后续补充到本节。

## 角色

| 角色 | 能做什么 | 权限如何保证 |
|---|---|---|
| 访客 | 注册、登录 | — |
| 普通用户 | 资料维护、联系人、建群、会话、消息、通话 | 前端路由守卫；后端不校验身份 |
| 群主 | 修改群资料、审批加群、移除成员、解散群 | 前端按 `owner_id` 显示操作；后端不校验 |
| 管理员 | 启用 / 禁用 / 删除用户与群聊，设置管理员 | 前端按 `is_admin` 显示入口；后端不校验 |

后端缺少认证与鉴权是当前最主要的风险，见 [tech-debt.md](../plans/tech-debt.md) TD-01。

## 核心业务场景

1. **注册登录**：手机号 + 短信验证码注册；密码或验证码登录。
2. **建立关系**：按 ID 申请加好友或加群，对方同意 / 拒绝 / 拉黑；群可设为直接加入。
3. **聊天**：在会话中收发文本和文件，在线时实时送达，离线时打开会话再读取历史。
4. **通话**：单聊中发起音视频通话，对方接听或拒绝，任一方可挂断。
5. **管控**：管理员禁用违规用户或群聊，被禁用者无法再被发起会话。

完整功能清单与实现状态见 [features.md](features.md)。

## 系统边界

**包含**：Vue 3 Web 前端；单实例 Go 后端（HTTPS 接口、WSS 长连接、静态文件）；MySQL、Redis；可选的 Kafka；阿里云短信；浏览器之间的 WebRTC 媒体流。

**当前不包含**：

- 移动端、桌面端客户端
- 离线推送、未读计数、已读回执、消息撤回、消息搜索
- 多人音视频通话、语音消息
- 找回密码、修改密码、注销账号
- 端到端加密、内容审核
- 多实例部署与水平扩展
